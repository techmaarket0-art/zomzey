01

Logo system

The same Z connecting two nodes — redrawn on one module so it is crisp from favicon to app icon.

  • Construction 32-unit tile, one module (s = 3) sets bar weight, node radius and corner radius. Nodes sit exactly where they always did — the Z still connects two points.
  • Lock-up Wordmark cap height = Z height, so tile and word share one horizon. Gap = 10 units. Clear space = ¼ tile on every side.
  • Sizes Lock-up ≥ 20px tall (header: 32px desktop, 26px mobile). Mark ≥ 24px. Below that use the favicon cut.
  • Don’t put the ink wordmark on violet, recolour the nodes (green means money), add gradients, shadows or outlines, or set the wordmark as live text.
